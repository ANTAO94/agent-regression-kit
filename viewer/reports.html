    生成索引 local / CI

    在报告目录上运行索引命令。默认不改变退出码；需要门禁时加上 --fail-on-regression。

    agent-regression report-index \
  --report-dir outputs \
  --out outputs/report-index.json

    怎么复核？ evidence path

    • 先看总览的 Failed 数量和状态。
    • 再按相对路径定位具体 compare JSON。
    • 打开 Trace Inspector 加载原始 JSON，查看事件和差异字段。
    打开 Trace Inspector →

    边界说明 read-only

    浏览器不能安全地自动读取同目录其他文件，所以索引负责导航，原始报告仍需由你显式选择。这样可避免静态页面越权读取本机文件。

    查看完整说明 →

    Report Index 是本地只读报告导航页。它不替代 Python compare/history，也不上传或修改你的回归证据。
