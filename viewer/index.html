执行命令 local / CI

页面只展示证据。要生成 candidate 和 compare JSON，请在项目里执行：

agent-regression compare \
  --baseline baselines/order-123.trace.json \
  --candidate work/order-123.trace.json \
  --format json \
  --out outputs/order-123.diff.json

这次失败说明什么？ read the path

  • 先看 category：变化属于工具、结果、claims 还是文本。
  • 再看 path：定位到 Trace 的具体字段。
  • 最后判断是 Bug、已知噪音，还是有意的产品变更。
