# v4.22 acceptance / v4.22 验收

## Scope / 范围

v4.22 expands the v4.21 AgentDojo intake smoke into a five-case,
checksum-pinned matrix. The matrix covers four AgentDojo suites and two
attack-path labels, while keeping each Contract independent from the upstream
`utility`/`security` oracle. It validates source identity, message conversion,
Contract behavior, label isolation and report/Trace artifacts in one CI gate.

v4.22 把 v4.21 的单条 AgentDojo 接入 smoke 扩展成五条固定哈希样本矩阵，覆盖四个
AgentDojo suite 和两种攻击路径标签。每条样本的 Contract 都独立于上游
`utility`/`security` oracle，统一检查来源身份、消息转换、契约行为、标签隔离和
报告/Trace 产物。

This remains an exported-run integration matrix. It is not a full AgentDojo
re-run, a security rate, a model comparison, or a universal generalization
claim.

这仍然是“外部导出运行结果接入”的矩阵验收，不是完整 AgentDojo 重跑、安全率、模型对比或
通用泛化结论。

## Reproduce / 复现

```bash
mkdir -p work/agentdojo-matrix/results work/agentdojo-matrix/traces

jq -r '.cases[] | [.download_url, .result_file] | @tsv' \
  examples/agentdojo/matrix.json | while IFS=$'\t' read -r url file; do
    curl --fail --location --retry 3 "$url" \
      -o "work/agentdojo-matrix/results/$file"
  done

PYTHONPATH=src python examples/agentdojo_matrix_validation.py \
  --manifest examples/agentdojo/matrix.json \
  --results-dir work/agentdojo-matrix/results \
  --out work/agentdojo-matrix/report.json \
  --trace-dir work/agentdojo-matrix/traces
```

The command writes one redacted report under `work/agentdojo-matrix/cases/`,
one redacted Trace per case and an aggregate report. The dedicated CI job is
`agentdojo-independent-source-matrix` in the
[tau2 independent validation workflow](https://github.com/ANTAO94/agent-regression-kit/actions/workflows/tau2-independent-validation.yml).

命令会在 `work/agentdojo-matrix/cases/` 写入每条脱敏报告，每条样本写入一份脱敏 Trace，
并写入一个汇总报告。专用 CI job 是 `agentdojo-independent-source-matrix`，位于
[tau2 independent validation workflow](https://github.com/ANTAO94/agent-regression-kit/actions/workflows/tau2-independent-validation.yml)。

## Decision boundary / 决策边界

The matrix manifest contains a reviewed Contract for each sample. The runner
never constructs a Contract from `utility` or `security`; those values are
retained only as external oracle fields and checked against the manifest after
the observable Trace behavior has been evaluated. A source hash mismatch is an
input error and fails closed before producing a trusted gate.

矩阵 manifest 为每条样本保存人工审阅过的 Contract。运行器绝不会从 `utility` 或 `security`
标签生成 Contract；它只在可观察 Trace 行为完成评估后，把标签保留为 external oracle 并与
manifest 预期值比对。来源哈希不匹配属于输入错误，会在生成可信 gate 前 fail closed。

## Tests and limits / 测试与限制

- v4.22 adds matrix parser, source binding, aggregate gate and artifact tests;
  the full local test count is recorded in the release result.
- The matrix samples are all exported runs from one pinned upstream revision
  and one model pipeline. They show cross-suite intake, not independent
  model-level generalization.
- The manually authored Contracts are path checks. They do not recreate the
  upstream simulator, environment state, user simulator or model execution.
- The human 30/60/90-minute usability study with people uninvolved in the
  implementation remains outstanding.

- v4.22 增加矩阵解析、来源绑定、汇总 gate 和产物测试；完整本地测试数量以发布结果为准。
- 所有样本来自同一个固定 upstream revision 和同一个模型 pipeline，证明的是跨 suite 接入，
  不是独立模型泛化。
- 人工编写的 Contract 是工具路径检查，不重建上游模拟器、环境状态、用户模拟器或模型运行。
- 未参与实现者的 30/60/90 分钟真实可用性研究仍未完成。
