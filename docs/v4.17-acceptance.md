# v4.17 acceptance / v4.17 验收

v4.17 hardens external evaluation provenance. A result file must match the
source manifest SHA-256 before the report is written, and a formal gate must
contain enough eligible samples and oracle failures. The release adds a
prospective o4-mini retail result file from the pinned tau2-bench tag.

v4.17 加固外部评测的可追溯性：结果文件在写报告前必须与 source manifest 的 SHA-256
一致，正式门禁必须满足可判定样本和失败样本下限。本版本新增固定 tau2-bench tag 下的
o4-mini retail 结果文件作为模型结果级 prospective evaluation。

## Acceptance matrix / 验收矩阵

| Check / 检查 | Evidence / 证据 | Result / 结果 |
| --- | --- | --- |
| Full core suite / 核心测试 | `python -m unittest discover -s tests -p 'test_*.py'` | 241 tests pass |
| Provenance mismatch / 哈希错配 | `tests/test_tau2_validation_script.py` | mismatched result file is rejected before report generation |
| Failure-count gate / 失败样本门禁 | `--min-failures 50` | gate fails closed below the threshold |
| Prospective source / prospective 来源 | `examples/tau2-retail/prospective-o4-mini-source.json` | immutable tag, URL and SHA-256 |
| Eligible samples / 可判定样本 | o4-mini retail result file | 420 (minimum 300) |
| Oracle failures / oracle 失败样本 | o4-mini retail result file | 126 (minimum 50) |
| Failure recall / 失败召回率 | generated report | 100% (threshold ≥99%) |
| False-alarm rate / 误报率 | generated report | 2.04% (threshold ≤5%) |
| Missed failures / 漏报 | generated report | 0 (threshold 0) |
| Result binding / 结果绑定 | report `provenance.results.results_sha256` | `7135f38bbbbd46d6babe830574c8623bb276d8fd6da316580b905cf513853f98` |
| CI / 持续集成 | [tau2 validation workflow](https://github.com/ANTAO94/agent-regression-kit/actions/workflows/tau2-independent-validation.yml) | calibration and prospective jobs both required |

## Reproduce / 复现

```bash
mkdir -p work/tau2-prospective
curl --fail --location --retry 3 \
  --output work/tau2-prospective/results.json \
  "https://raw.githubusercontent.com/sierra-research/tau2-bench/v1.0.1/data/tau2/results/final/o4-mini-2025-04-16_retail_default_gpt-4.1-2025-04-14_4trials.json"

echo "7135f38bbbbd46d6babe830574c8623bb276d8fd6da316580b905cf513853f98  work/tau2-prospective/results.json" \
  | shasum -a 256 -c -

python3 examples/tau2_retail_validation.py \
  --results work/tau2-prospective/results.json \
  --source-manifest examples/tau2-retail/prospective-o4-mini-source.json \
  --out work/tau2-prospective/report.json \
  --min-eligible 300 \
  --min-failures 50 \
  --min-failure-recall 0.99 \
  --max-false-alarm-rate 0.05 \
  --max-missed-failure-rate 0.0
```

## Boundary / 边界

The o4-mini file is a separate published result file and was not used in the
earlier v4.13 calibration run. It is therefore useful prospective model-level
evidence. The task family, task definitions and upstream oracle remain shared
with the calibration source; this is not an unseen-domain or independent-task
generalization claim.

o4-mini 文件是独立的已发布结果文件，没有参与早期 v4.13 calibration，因此可以作为
模型结果级的 prospective evidence。但任务域、任务定义和 upstream oracle 与 calibration
来源相同；本验收不声称未见任务域泛化或完全独立任务集泛化。
