# v4.18 acceptance / v4.18 验收

v4.18 adds explicit noise filtering for path contracts and a second τ²-bench
domain. The release keeps business identifiers strict while allowing an
unmodeled transport field to vary.

v4.18 增加路径契约的显式噪音过滤，并接入 τ²-bench 的第二个任务域。版本仍然严格检查业务
标识；只有 Contract 没有声明的、明确列入忽略列表的传输字段才允许变化。

## New configuration / 新配置

Use `path_rules.ignore_argument_paths` for fields that are transport noise in
this path contract. Paths are relative to the tool call's `arguments` object:

```json
{
  "contract": {
    "path_rules": {
      "mode": "unordered_subset",
      "any_of": [[
        {"tool": "update_reservation_flights", "arguments": {
          "reservation_id": "R1",
          "cabin": "economy"
        }}
      ]],
      "ignore_argument_paths": ["payment_id"]
    }
  }
}
```

The field is intentionally not a wildcard. If the expected rule explicitly
contains `payment_id`, that value remains checked; the ignore list does not
turn it into an arbitrary payment method. This makes the rule suitable for a
baseline that does not model a request ID while preserving business safety.

`path_rules.ignore_argument_paths` is different from
`state_equivalence.ignore_argument_paths`: the former controls matching of
declared path rules, while the latter groups already declared outcome intents.

## Reproduce / 复现

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -p 'test_*.py'

python examples/tau2_airline_validation.py \
  --results work/tau2-airline/results.json \
  --out work/tau2-airline/report.json \
  --min-eligible 100 \
  --min-failures 50 \
  --min-failure-recall 0.99 \
  --max-false-alarm-rate 0.05 \
  --max-missed-failure-rate 0.0
```

The source manifests and download instructions are in
[`examples/tau2-airline/README.md`](../examples/tau2-airline/README.md). The
GitHub Actions workflow runs four independent jobs: the published and
prospective retail checks, plus the published and prospective airline checks.

## Interpretation and limitations / 解释与限制

- The airline result is a second domain from the same upstream benchmark
  release. It is cross-domain transfer evidence, not proof of every unseen
  task distribution.
- The published airline gate uses the project's normal 5% false-alarm target.
- The prospective o4-mini airline result observed a 10.42% false-alarm rate;
  its workflow uses an explicit 12% observation threshold and reports that
  relaxation. It must not be summarized as a general 5% guarantee.
- The airline slice has 120 eligible scenarios, below the roadmap's 300-sample
  final maturity threshold. The raw count is reported instead of hiding this
  limitation.
- A study with a user who did not participate in implementation is still
  required for the human usability criterion.

上面的限制不是测试失败被隐藏，而是版本验收的一部分：v4.18 证明了路径噪音字段可以显式
管理，并且契约逻辑可以跨到航空域；它还没有证明未见任务分布上的完整泛化，也没有完成独立
使用者的人因验收。
