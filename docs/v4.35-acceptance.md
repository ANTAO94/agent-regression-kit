# v4.35 acceptance / v4.35 验收

## Scope / 范围

v4.35 adds a final-v4 readiness audit. It does not change Trace, Contract,
study or `PUBLIC_API_VERSION=4` compatibility. A readiness manifest references
reports and evidence files by relative path and SHA-256; the CLI re-reads the
structured report fields before deciding whether the final maturity gates are
met.

v4.35 增加 final-v4 readiness 审计，不改变 Trace、Contract、study 或
`PUBLIC_API_VERSION=4` 兼容边界。readiness manifest 通过相对路径和 SHA-256 引用报告/证据，CLI 会重新读取
报告结构化字段，再判断最终成熟度门槛是否满足。

## CLI contract / CLI 契约

```bash
agent-regression readiness \
  --manifest work/readiness.json \
  --format markdown \
  --out work/readiness.md
```

The `final-v4` profile enforces:

| Gate | Required value |
| --- | ---: |
| Evaluated held-out samples | ≥ 300 |
| Failure samples | ≥ 50 |
| Failure recall | ≥ 0.99 |
| False-alarm rate | ≤ 0.05 |
| Small performance traces | ≥ 10,000 |
| Small workload time | ≤ 60 seconds |
| Peak RSS | < 512 MiB |

The manifest can make a threshold stricter, but never weaker. The command
returns `0` only when all required checks pass, `1` when the manifest is valid
but a required check is failed or pending, and `2` for invalid input, path
escape or digest mismatch.

`external` checks are intentionally explicit. A first-user usability study or
a genuinely unseen task-domain evaluation stays `pending` until an independent
artifact is reviewed and referenced. A maintainer's local run is not accepted
as either proof.

## Local evidence / 本地证据

The v4.35 source tree passes **291 tests** with `PYTHONPATH=src`. The focused
readiness tests cover:

- passing benchmark and performance threshold checks;
- an explicit pending external check that makes the audit `NOT READY`;
- independent Markdown rendering and CLI exit code `1` for pending evidence;
- SHA-256 mismatch rejection;
- rejection of thresholds weakened below the final-v4 profile.

The existing 287-test v4.34 suite remains part of the full run. Package build,
clean-environment installation and CLI help are release gates as well.

v4.35 源码树在 `PYTHONPATH=src` 下通过 **291 项测试**。新增测试覆盖量化门槛、pending external、Markdown 输出、
退出码、SHA-256 篡改和降低门槛负向场景；v4.34 的 287 项既有测试也全部保留。构建、全新环境安装和 CLI help
仍是发布门禁。

## Public API / 公共 API

```python
from agent_regression import evaluate_readiness

report = evaluate_readiness("work/readiness.json")
assert report["ok"] is True
if not report["ready"]:
    print("external or quantitative evidence is still pending")
```

The report contains check IDs, statuses, observed metrics, referenced paths
and digests. It does not copy benchmark labels, Trace contents, prompts or
descriptor contents into the report.

## Compatibility / 兼容性

- `PUBLIC_API_VERSION=4` remains unchanged.
- Trace, Contract, report and study schema versions remain unchanged.
- Existing commands and manifests do not need migration.
- The new readiness manifest uses `schema_version=0.1` and is opt-in.
- `final-v4` is deliberately the only built-in profile; a weaker custom profile
  cannot be used to claim final maturity.

## Release boundary / 发布边界

The readiness command verifies evidence integrity, report shape and explicit
thresholds. It does not prove that a provider, model, dataset, participant or
business oracle is truthful. The real first-user study and genuinely unseen
task-domain evaluation remain external acceptance requirements until actual
independent evidence is supplied.

readiness 命令证明的是证据字节完整、报告结构正确和门槛满足，不证明供应商、模型、数据集、参与者或业务 oracle
本身真实。真实首次用户研究和真正未见任务域评测必须等独立证据完成后再更新为 passed。
