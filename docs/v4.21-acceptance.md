# v4.21 acceptance / v4.21 验收

## Scope / 范围

v4.21 adds an independent-source bridge for one exported AgentDojo run. It is
deliberately an intake and contract smoke, not a claim that one public sample
represents the full AgentDojo benchmark or all prompt-injection behavior.

v4.21 增加了一个独立来源接入桥，用于导入一条公开 AgentDojo 运行结果并执行确定性契约。
它是“外部来源是否能接入”的 smoke 验收，不把一个样本包装成完整 AgentDojo 基准或通用
提示注入安全结论。

AgentDojo's exported run contains assistant messages, tool calls/results, a
final answer, and external `utility`/`security` outcomes. The bridge accepts
both the string-function shape used by the pinned file (`function: "name",
args: {...}`) and the object-function shape used by common OpenAI-compatible
exporters (`function: {"name": "name", "args": {...}}`).

AgentDojo 的运行文件包含 assistant 消息、工具调用/结果、最终回答以及外部
`utility`/`security` 结果。接入桥同时兼容固定文件使用的字符串函数格式和常见 OpenAI
兼容导出器使用的对象函数格式。

The report keeps the upstream labels as `external_oracle`; it does not copy
them into Trace metadata, generate Contract rules from them, or silently
reinterpret the meaning of `security=false`. The CI gate requires the pinned
Contract to pass and the expected external labels to match the source manifest.

报告把上游标签保留在 `external_oracle` 字段中，不复制到 Trace metadata，不用标签生成
Contract，也不擅自解释 `security=false` 的含义。CI 同时要求固定 Contract 通过，且外部
标签与 source manifest 中的预期值一致。

The separately maintained [consumer pilot](consumer-pilot.md) installs the

## Reproduce / 复现

```bash
mkdir -p work/agentdojo
curl -L -o work/agentdojo/run.json \
  https://raw.githubusercontent.com/ethz-spylab/agentdojo/089ed468cf3ed0322acc66b0211f26d9d90dbf60/runs/gpt-4o-2024-05-13/workspace/user_task_0/direct/injection_task_0.json
shasum -a 256 work/agentdojo/run.json

PYTHONPATH=src python examples/agentdojo_validation.py \
  --results work/agentdojo/run.json \
  --source-manifest examples/agentdojo/source.json \
  --out work/agentdojo/report.json \
  --trace-out work/agentdojo/agent-trace.json
```

Expected summary: `contract_passed=true`, `utility=true`, `security=false`,
`gate_passed=true`, and the result SHA-256 above. The dedicated workflow is
[`tau2 independent validation`](https://github.com/ANTAO94/agent-regression-kit/actions/workflows/tau2-independent-validation.yml);
the job is named `agentdojo-independent-source-smoke` and uploads the report
and converted Trace as an artifact.

预期摘要为 `contract_passed=true`、`utility=true`、`security=false`、
`gate_passed=true`，并且结果 SHA-256 与上表一致。专用 workflow 中的 job 名称为
`agentdojo-independent-source-smoke`，会上传报告和转换后的 Trace。

## Interpretation and limits / 解释与限制

- This proves an independently maintained exported run can cross the public
  `AgentTrace` and Contract boundary without leaking the external oracle into
  the decision input.
- It is one pinned run from one AgentDojo suite/model/attack combination. It
  is not a full AgentDojo re-run, security rate, prompt-injection defense
  guarantee, or production reliability result.
- The bridge imports observable messages only. It does not recreate AgentDojo's
  environment, task implementation, user simulator, or model execution.
- A future release must add more AgentDojo suites and an independently
  reviewed sample matrix before making cross-source quantitative claims.
- The uninvolved human 30/60/90-minute usability study remains outstanding.

- 这证明独立维护的外部运行结果可以跨过公开 `AgentTrace`/Contract 边界，且外部 oracle
  不会泄漏到决策输入中。
- 目前只有一个固定的 suite/model/attack 组合样本，不是完整 AgentDojo 重跑，不是安全率、
  提示注入防御保证，也不是生产可靠性结果。
- 接入桥只导入可观察消息，不重建 AgentDojo 环境、任务实现、用户模拟器或模型运行。
- 后续必须增加更多 AgentDojo suite 和经独立审查的样本矩阵，才能做跨来源定量结论。
- 未参与实现者的 30/60/90 分钟可用性研究仍未完成。
