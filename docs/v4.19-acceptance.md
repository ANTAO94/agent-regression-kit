# v4.19 acceptance / v4.19 验收

## Scope / 范围

v4.19 adds an actor-aware telecom adapter for the pinned `tau2-bench`
`v1.0.1` release. Telecom simulations contain two kinds of tool activity:

- `assistant` calls are the Agent behavior path and are checked against the
  declared write contract.
- `user` calls are simulator/environment activity. They are retained as
  evidence for environment assertions, but are never allowed to satisfy an
  assistant-owned business action.

v4.19 增加了面向固定 `tau2-bench` `v1.0.1` 的电信域适配器。电信轨迹包含两类工具
活动：`assistant` 调用属于 Agent 行为，参与业务契约检查；`user` 调用属于模拟器或
环境活动，只能作为环境断言证据，不能冒充 Agent 完成业务动作。

## Reproduce / 复现

```bash
mkdir -p work/tau2-telecom
curl --fail --location --retry 3 \
  --output work/tau2-telecom/results.json \
  "https://raw.githubusercontent.com/sierra-research/tau2-bench/v1.0.1/data/tau2/results/final/gpt-4.1-mini-2025-04-14_telecom_base_gpt-4.1-2025-04-14_4trials.json"
echo "04fad1a6fb3ff8804be31c54cf5a993b64868e37683c226e014e7adbf60841d9  work/tau2-telecom/results.json" \
  | shasum -a 256 -c -
PYTHONPATH=src python examples/tau2_telecom_validation.py \
  --results work/tau2-telecom/results.json \
  --source-manifest examples/tau2-telecom/source.json \
  --out work/tau2-telecom/report.json \
  --traces-dir work/tau2-telecom/sample-traces \
  --min-eligible 300 \
  --min-failures 200 \
  --min-failure-recall 0.99 \
  --max-false-alarm-rate 0.05 \
  --max-missed-failure-rate 0.0
```

The prospective file is run with the matching prospective manifest and the
thresholds documented above. A result/manifest mismatch must fail before a
report is written.

前瞻文件必须配套使用前瞻 manifest；结果文件和 manifest 不匹配时，校验器必须在写报告前
失败，避免把一个模型的指标误标为另一个模型的结果。

## Interpretation and limitations / 如何解释与限制

The published telecom result is cross-domain calibration evidence. Its labels
and task semantics informed the adapter, so the 100% scoped result is not an
unseen-task generalization score. The prospective file is a model-result-level
check over the same task family, not an independent task-domain holdout.

公开电信结果属于跨域校准证据：任务语义参与了适配器设计，因此 100% 的范围内结果不能
称为未见任务泛化成绩。前瞻 o4-mini 文件只是同一任务族上的模型结果级检查，也不是独立
任务域留出评测。

The adapter intentionally covers a bounded set of telecom environment
assertions. It does not claim to reconstruct every hidden simulator state. For
production use, teams should add domain-owned result parsers and fixtures,
then run the generic `benchmark prepare/decide/score` workflow on a genuinely
held-out set.

适配器只覆盖有限的电信环境断言，不声称可以还原模拟器的全部隐藏状态。生产使用时，应由
业务方继续补充领域结果解析器和 fixture，并在真正留出的数据集上运行通用的
`benchmark prepare/decide/score` 流程。
