# v4.39 source acceptance / v4.39 源码验收

Date / 日期: 2026-09-23. Status / 状态: implemented in the working tree; no version bump, tag, push, or release.
当前 v4.39 功能已实现于工作树；尚未改版本号、打 tag、推送或发布。

The published release remains v4.38.1. This record covers unreleased source changes implementing the reviewed lifecycle from failure evidence to an EvaluationCase and CI CaseRun suite.
当前正式发布版仍为 v4.38.1。本记录针对尚未发布的源码改动：把失败证据沉淀为审核用例，并在 CI 中执行 CaseRun 套件。

## Scope / 范围

The implementation adds `Incident`, `EvaluationCase`, and `CaseRun`; redacted incident import; case draft, revision, validation, and positive/negative approval; single-case and explicit-manifest suite comparison; JSON Schemas; a fixed HelpPilot Agent fixture and GitHub Actions workflow; and bilingual user guides. Session-kind cases are explicitly rejected and remain outside this release slice.

本轮新增 `Incident`、`EvaluationCase`、`CaseRun`；支持脱敏导入问题证据、创建/修订/校验用例、使用正反样本审核，以及单例和显式清单套件比较；另含 JSON Schema、固定 HelpPilot Agent 示例、GitHub Actions 工作流和双语指南。Session 类型用例会明确拒绝，不在本轮支持范围内。

The plan and actual CLI are documented in [the iteration design](next-iteration-closed-loop.zh-CN.md), the [Chinese guide](case-lifecycle.zh-CN.md), and the [English guide](case-lifecycle.en.md).

## Local source verification / 本地源码验证

On CPython 3.9.6, the full suite passed **323 tests**:

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src python3 -m unittest discover -s tests -v
```

The focused lifecycle suite passed **6 tests**. Existing compare, session, and CLI regression groups also passed (12, 6, and 10 tests respectively). Syntax compilation covered 53 Python source files. `git diff --check` passed.

Python 3.9.6 上完整测试套件 **323 项通过**。用例生命周期定向套件 **6 项通过**；原有 compare、session、CLI 回归组分别通过 12、6、10 项。53 个 Python 源文件语法编译通过，`git diff --check` 通过。

The four new schemas parse as JSON and validate against Draft 2020-12. Six representative objects passed schema validation, including Incident, EvaluationCase, and a CaseRun emitted by the CLI. The suite schema is an input manifest, not a separate generated result type. Fourteen evidence references in the HelpPilot bundle were checked for bundle-relative paths, file existence, and matching SHA-256. Tested boundaries include redaction and run-ID binding; draft/approval and rejection cases; pass/fail/error exit codes; sidecar report hashes; invalidated references; empty/duplicate/failing suites; symlink/path traversal; and session rejection.

新增四份 Schema 均可解析并符合 Draft 2020-12；六个代表性对象通过校验，包含 Incident、EvaluationCase 和 CLI 生成的 CaseRun。Suite Schema 描述输入清单，而不是单独的输出对象。HelpPilot bundle 的 14 个证据引用均验证了 bundle 相对路径、文件存在和 SHA-256 匹配。已测试脱敏与运行 ID 绑定、草稿与审核拒绝条件、通过/失败/错误退出码、sidecar 报告哈希、引用失效、空/重复/失败套件、软链接和路径穿越，以及 session 拒绝。
