# v4.24 acceptance / v4.24 验收

## Scope / 范围

v4.24 makes the reviewed Contract itself auditable before matrix results are
read. Each case binds its Contract to a SHA-256 digest of canonical JSON, and
the manifest declares that the Contract was frozen before the external oracle
is considered. A missing or modified Contract fails closed.

v4.24 把“评测规则本身是否在看结果前冻结”落成可验证能力。每条样本都对 Contract 的
规范化 JSON 计算 SHA-256，manifest 声明 Contract 必须在读取外部 oracle 前冻结；Contract
缺失或被修改时，验证器 fail closed。

The eight cases are the v4.23 cross-model matrix: four `gpt-4o-2024-05-13`
direct positive controls and four `gpt-4o-mini-2024-07-18`
`important_instructions` attack trajectories. The expected-block semantics
remain explicit: four attack cases must actually fail their Contract.

八条样本沿用 v4.23 跨模型矩阵：四条 `gpt-4o-2024-05-13` direct 正向对照和四条
`gpt-4o-mini-2024-07-18` `important_instructions` 攻击轨迹。预期阻断语义保持显式：
四条攻击样本的 Contract 必须实际失败。

`contract_sha256` 对排序、紧凑化后的 Contract JSON 计算，不是报告、结果文件或 upstream
oracle 标签的哈希。

## Acceptance matrix / 验收矩阵

| Group | Cases | Expected Contract outcome | Observed | Contract provenance |
| --- | ---: | ---: | ---: | ---: |
| gpt-4o direct controls | 4 | pass | 4/4 pass | 4/4 bound |
| gpt-4o-mini attack paths | 4 | block | 4/4 block | 4/4 bound |

The validator also checks the immutable result revision and SHA-256, pipeline
metadata, external oracle values and the absence of `utility/security` labels
from Trace. The upstream labels remain external evidence; they do not generate
the Contract.

验证器还会检查不可变 revision 和结果 SHA-256、pipeline 元数据、外部 oracle 值以及
Trace 中不能出现 `utility/security` 标签。upstream 标签仍然是外部证据，不会生成 Contract。

## Reproduce locally / 本地复现

```bash
mkdir -p work/agentdojo-pre-registered/results
python - <<'PY'
import json
from pathlib import Path
from urllib.request import urlopen

manifest = json.loads(Path("examples/agentdojo/matrix-v4.24.json").read_text())
result_dir = Path("work/agentdojo-pre-registered/results")
for case in manifest["cases"]:
    with urlopen(case["download_url"]) as response:
        (result_dir / case["result_file"]).write_bytes(response.read())
PY

PYTHONPATH=src python examples/agentdojo_matrix_validation.py \
  --manifest examples/agentdojo/matrix-v4.24.json \
  --results-dir work/agentdojo-pre-registered/results \
  --out work/agentdojo-pre-registered/report.json \
  --trace-dir work/agentdojo-pre-registered/traces
```

The local result was:

```text
case_count=8
passed_case_count=8
contract_blocks=4
all_contract_provenance_bound=true
gate_passed=true
```

The focused negative test changes a Contract after its digest is declared and
expects `Contract SHA-256 mismatch`; it does not allow the modified rule to be
used for scoring.

本地结果为 8 条样本、8 条 gate 通过、4 条 Contract 实际阻断、8/8 Contract provenance
绑定通过。专项负向测试在声明 digest 后修改 Contract，必须得到 `Contract SHA-256 mismatch`，
不能用修改后的规则继续评分。

## Boundaries / 边界

- Contract pre-registration proves rule provenance, not that the rule is
  complete or semantically correct.
- The matrix still uses pinned exported runs, not a full AgentDojo simulator or
  provider rerun.
- Four attack cases and two model pipelines are not a security rate or a
  universal cross-model generalization result.
- External utility/security labels remain separate from Trace and Contract;
  passing this gate does not guarantee production authorization or safety.
- An uninvolved human usability study and repeated-run variance evidence are
  still required before claiming the final maturity target.

- Contract 预注册证明的是规则来源没有被偷偷改写，不证明规则完整或语义一定正确。
- 矩阵仍使用固定导出运行结果，不是完整 AgentDojo simulator 或模型服务重跑。
- 四条攻击样本和两个模型 pipeline 不是安全率，也不是通用跨模型泛化证明。
- 外部 utility/security 标签仍与 Trace、Contract 分离；通过本 gate 不代表生产授权或安全。
- 在宣称最终成熟度前，还需要未参与实现人员的可用性研究和重复运行方差证据。
