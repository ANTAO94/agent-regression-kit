# v4.13 acceptance / v4.13 验收

v4.13 hardens the boundary between “the Agent eventually did the intended
thing” and “a failed attempt happened to look like the intended thing”. It also
lets a Contract say whether only declared outcome paths matter or whether the
rest of the observed world state must remain unchanged.

v4.13 加固了“Agent 最终成功完成意图”和“失败尝试碰巧匹配预期动作”之间的边界，并允许
Contract 明确：只检查声明的最终状态，还是同时要求其余可观测状态保持不变。

## Explicit policy example / 严格策略示例

```json
{
  "contract": {
    "state_equivalence": {
      "mode": "outcome",
      "paths": ["world_state.final.orders.123.status"],
      "state_scope": "declared_and_unchanged_rest",
      "attempt_policy": {
        "require_success": true,
        "allow_failed_before_success": true,
        "max_failed_attempts": 1
      }
    }
  }
}
```

This means: one failed attempt may be observed, but it cannot replace a
successful matching call; a second failed attempt blocks; the declared order
status must be present and equal; and all other non-ignored world-state fields
must remain unchanged.

这表示：允许观察到一次失败尝试，但失败不能代替成功匹配；第二次失败会阻断；声明的订单
状态必须存在且相等；其余未被忽略的 world state 字段必须保持不变。

## Compatibility and τ² boundary / 兼容性与 τ² 边界

Older configurations containing only `allow_failed_expected` remain readable.
`agent-regression config` and `agent-regression check` return a non-blocking
`legacy_allow_failed_expected` diagnostic with a migration suggestion. New
ordinary Agent regression configurations should use the strict `attempt_policy`
default. The τ² adapter intentionally declares `require_success=false` because
its published reward is the external oracle and the fixed file contains
reward-positive simulations whose expected write tool reports an error; this is
an adapter-specific benchmark interpretation, not the recommended default for
application regressions.

只包含 `allow_failed_expected` 的旧配置仍可读取。`agent-regression config` 和
`agent-regression check` 会返回非阻断的 `legacy_allow_failed_expected` 诊断和迁移建议。普通
Agent 回归配置应使用严格的 `attempt_policy` 默认值。τ² 适配器显式声明
`require_success=false`，因为其 published reward 是外部 oracle，固定文件中存在“预期写入工具
返回错误但 reward 为正”的样本；这只是该基准的适配语义，不是业务回归的推荐默认值。
