# Agent Regression Kit v4.4 Acceptance / v4.4 验收说明

v4.4 strengthens release integrity and open-source governance without changing
public API generation 4 or Trace schema 0.1.

v4.4 提升发布完整性和开源治理，不改变公共 API 代际 4 或 Trace schema 0.1。

## Acceptance contract / 验收契约

- full offline test suite passes on Python 3.9, 3.11 and 3.13;
- framework and live-provider checks remain green;
- wheel and source distribution install successfully in a clean environment;
- every release wheel/source archive appears in `SHA256SUMS`;
- the SPDX 2.3 document contains each release artifact and SHA-256 digest;
- tagged artifacts receive GitHub SLSA provenance and SBOM attestations;
- release archives include the supply-chain verification guide;
- vulnerability reporting, conduct, issue templates and Dependabot are present.

- Python 3.9、3.11、3.13 全量离线测试通过；
- 真实框架和在线供应商检查保持通过；
- wheel 与源码包可在干净环境安装；
- `SHA256SUMS` 覆盖全部 wheel 和源码包；
- SPDX 2.3 文档包含每个发布制品及其 SHA-256；
- tag 制品具有 GitHub SLSA provenance 与 SBOM attestations；
- 安装包包含供应链验证说明；
- 安全披露、社区准则、Issue 模板和 Dependabot 已配置。

The SBOM inventories release artifacts and the dependency-free core. It does
not inventory optional dependencies installed later by a consuming project.
An attestation proves origin and integrity, not business correctness.

SBOM 清点发布制品和零依赖核心，不清点使用方后来安装的可选依赖。Attestation
证明来源和完整性，不证明业务正确性。
