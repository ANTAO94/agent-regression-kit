## What is covered / 覆盖范围

The consumer Contract checks two dependent tool calls, a cross-step customer ID
relation, structured claims, an unauthorized-tool boundary and a step limit.
Each injected error is implemented in the consumer repository, not in the core
framework. The reports retain category/path evidence so a reviewer can see why
the gate failed.

消费 Contract 检查两次有依赖的工具调用、跨步骤 customer ID 关系、结构化 claims、未授权工具
边界和步数上限。三类错误均由消费仓库注入，而不是核心框架预置；报告保留 category/path 证据，
便于审查失败原因。

## Boundary / 边界

This is one independent deterministic consumer project. It proves release
installation, public API use, CLI exit-code behavior and three representative
regression boundaries. It does not claim automatic support for every Agent
framework, online provider, asynchronous lifecycle or production deployment.

这是一个独立的确定性消费项目，证明发布安装、公开 API、CLI 退出码和三类代表性回归边界；不
宣称自动支持所有 Agent 框架、在线供应商、异步生命周期或生产部署。
