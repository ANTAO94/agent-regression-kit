# v4.25 acceptance / v4.25 验收

## Scope / 范围

v4.25 adds a repeatability gate for the pinned v4.24 AgentDojo matrix. The
validator runs the same decision pipeline three times and compares the
aggregate report, every case report and every converted Trace by SHA-256.
This makes deterministic artifact generation an explicit CI check instead of
an assumption.

v4.25 为固定的 v4.24 AgentDojo 矩阵增加重复性门禁。验证器对同一组输入运行三次，分别比较
汇总报告、每条 case 报告和每条转换 Trace 的 SHA-256，把“产物可重复生成”从默认假设变成
显式 CI 检查。

This is intentionally narrower than a stochastic model study: the inputs are
the same pinned exported runs. A stable result proves decision and artifact
reproducibility; it does not prove that an online model will choose the same
trajectory on every sampling run.

这不是在线模型随机性研究：三次运行使用同一批固定导出结果。稳定 hash 证明决策和产物生成
可重复，不证明在线模型每次采样都会走同一条路径。

## Reproduce locally / 本地复现

Download the result files exactly as described by the manifest, then run:

```bash
mkdir -p work/agentdojo-repeatability/results
python - <<'PY'
import json
from pathlib import Path
from urllib.request import urlopen

manifest = json.loads(Path("examples/agentdojo/matrix-v4.24.json").read_text())
result_dir = Path("work/agentdojo-repeatability/results")
for case in manifest["cases"]:
    with urlopen(case["download_url"]) as response:
        (result_dir / case["result_file"]).write_bytes(response.read())
PY

PYTHONPATH=src python examples/agentdojo_repeatability_validation.py \
  --manifest examples/agentdojo/matrix-v4.24.json \
  --results-dir work/agentdojo-repeatability/results \
  --out work/agentdojo-repeatability/report.json \
  --repeats 3
```

Expected output is `run_count=3`, `stable=true` and `gate_passed=true`. The
report records aggregate, per-case and Trace hashes for each repeat. A failed
inner matrix gate or any changed hash fails the repeatability gate.

预期输出为 `run_count=3`、`stable=true`、`gate_passed=true`。报告会记录每次重复的汇总报告、
逐条 case 报告和 Trace hash；内部矩阵 gate 失败或任一 hash 变化都会使重复性 gate 失败。

## Boundaries / 边界

- Repeatability checks deterministic decision/artifact generation over pinned
  inputs; they do not measure online model sampling variance.
- The matrix remains eight exported cases, four expected Contract blocks and
  two model pipelines; this is not a security rate or universal generalization
  claim.
- Contract completeness, independent user usability and a larger unseen task
  family remain separate maturity requirements.

- 重复性门禁只检查固定输入下的确定性决策和产物生成，不测在线模型采样方差。
- 矩阵仍是八条导出样本、四条预期 Contract 阻断和两个模型 pipeline，不是安全率或通用泛化
  结论。
- Contract 完整性、独立用户可用性和更大规模未见任务族仍是独立的成熟度要求。
