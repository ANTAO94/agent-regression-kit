# v4.38.1 patch acceptance / 补丁验收

Date / 日期: 2026-09-23. Status / 状态: [v4.38.1 released](https://github.com/ANTAO94/agent-regression-kit/releases/tag/v4.38.1).
The local checks below preceded the release; the tag-triggered [release workflow](https://github.com/ANTAO94/agent-regression-kit/actions/runs/35813034766)
then passed and published the wheel, sdist, checksums, SPDX SBOM, and provenance attestations.
以下本地验收在发布前完成；之后 tag 触发的发布工作流通过，并生成 wheel、sdist、校验和、
SPDX SBOM 和来源证明。

## Scope / 范围

This patch corrects four issues found after v4.38.0: generated CI uses the
`v`-prefixed tag; HelpPilot reply claims derive from the actual reply and fail
closed on missing supported facts; all logged actions, including unexpected
writes, remain visible; and recorded retrieval results include the consumed
body, not just its ID. The fixture Baseline and Contract were reviewed for the
expanded evidence. Trace schema, public comparison API and exit codes are
unchanged. See [CHANGELOG](../CHANGELOG.md), [UPGRADING](../UPGRADING.md),
and the [case study](helppilot-case-study.md).

本补丁修正 v4.38.0 后复审发现的四处问题：生成的 CI 使用带 `v` 的 tag；HelpPilot
claims 从实际回复解析且事实缺失时关闭通过；所有已记录动作（含额外写操作）均保留；
检索结果记录 Agent 消费的正文而不只是 ID。fixture Baseline 和 Contract 已按扩展证据复审。
Trace schema、公开比较 API 和退出码不变。见 [CHANGELOG](../CHANGELOG.md)、
[UPGRADING](../UPGRADING.md) 和[案例](helppilot-case-study.md)。

## Local acceptance / 本地验收

On 2026-09-23, the source suite passed with
`PYTHONPATH=src python3 -m unittest discover -s tests -v`: 317 tests on
Python 3.9.6 and 317 on Python 3.11.16. A temporary source copy built both
sdist and wheel with `python3 -m build --sdist --wheel`; a clean Python 3.11
venv installed the wheel. Installed metadata reported `4.38.1`, imports came
from that venv, CLI smoke checks and `uv pip check` passed, and both new docs
were present in sdist, wheel and installed share docs. The only build warning
was setuptools' deprecation notice for the existing license classifier.

2026-09-23 本地源码测试命令 `PYTHONPATH=src python3 -m unittest discover -s tests -v`
在 Python 3.9.6 与 3.11.16 各通过 317 项。临时源码副本成功构建 sdist 和 wheel；
干净的 Python 3.11 环境安装 wheel 后，版本为 `4.38.1`，导入路径位于该环境，CLI
冒烟检查和 `uv pip check` 通过；两篇新文档均出现在 sdist、wheel 和已安装文档目录中。
构建仅有现存 license classifier 的 setuptools 弃用警告。

The pinned HelpPilot commit `3767824fb90b89a8b19fc4169d912645aaf6fe0b`
ran with the installed wheel under Python 3.13.15. The normal Candidate
compared with exit `0`; approval boundary and refund-claim checks passed.
Each negative run exited `1` and contained the expected category:
`wrong-resource` → `tool_argument_policy`, `skip-tool` → `required_tool`,
`misread-result` → `contract_assertion`, `extra-write` →
`unauthorized_tool_call`, `corrupt-policy` → `tool_result`.

固定 HelpPilot commit 使用已安装 wheel 在 Python 3.13.15 下运行，正常 Candidate
比较退出码为 `0`，审批边界与退款 claims 检查通过；五个负向注入均以 `1` 退出并命中上列
预期类别。具体复现命令见[案例](helppilot-case-study.md)及
[HelpPilot workflow](../.github/workflows/helppilot-external-pilot.yml)。

The [main-branch CI suite](https://github.com/ANTAO94/agent-regression-kit/actions/runs/35812915376)
and the [HelpPilot external pilot](https://github.com/ANTAO94/agent-regression-kit/actions/runs/35812915388)
also passed on the tagged commit. These results validate the released artifact's
build and deterministic pilot, not independent adoption or production quality.
同一提交上的主分支 CI 和 HelpPilot 外部预演也通过；它们验证了发布包的构建与确定性
预演，但不代表独立项目已采用或具备生产质量。
