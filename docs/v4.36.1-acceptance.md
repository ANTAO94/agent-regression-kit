# v4.36.1 Acceptance Record / 验收记录

Date / 日期: 2026-09-21

## Release intent / 发布目标

v4.36.1 is a compatibility patch for the independent LangGraph pilot and the
project onboarding path. It does not change `PUBLIC_API_VERSION`, Trace schema,
Contract schema or comparison configuration.

v4.36.1 是针对独立 LangGraph 接入与项目上手路径的兼容性补丁。它不修改
`PUBLIC_API_VERSION`、Trace schema、Contract schema 或比较配置。

## Accepted behavior / 已验收行为

- The result recorded in each Trace tool call is the exact payload returned to
  and consumed by the Agent.
- Structured claims are parsed from consumed evidence content, not copied from
  fixture expectations.
- Evidence corruption is blocked even when the corrupted document preserves
  its original document ID.
- Normal, wording-variation and evidence-order-variation runs pass.
- Wrong-query, skipped-tool, result-misread and corrupted-evidence runs fail
  with explicit comparison categories.
- The bilingual README presents a verified five-minute quick start, the
  integration boundary, Contract configuration and CI usage.

- 每个 Trace 工具调用中记录的结果，都是返回给 Agent 并被 Agent 实际消费的原始载荷。
- 结构化 claims 从已消费证据内容解析，不从 fixture 期望值复制。
- 即使损坏的文档保留原始文档 ID，证据内容损坏仍会被门禁拦截。
- 正常、措辞变化、证据顺序变化场景通过。
- 错误查询、跳过工具、结果误读、证据损坏场景以明确差异类别失败。
- 中英文 README 均提供经过验证的五分钟快速开始、接入边界、Contract 配置和 CI 用法。

the pinned independent project. It does **not** prove online model quality,
upstream adoption, first-time user usability or production business value.

这些结果证明了针对固定独立项目的确定性接入和回归检测能力，但**不代表**在线模型质量、
上游项目采用、首次用户可用性或生产业务价值已经得到证明。
