# v4.36 acceptance / v4.36 验收

## Scope / 范围

v4.36 implements the P1 technical-preview slice of the new product iteration
plan. It adds a reusable LangGraph v2 lifecycle adapter and verifies it against
the pinned public project
[`Brescou/langgraph-agent-stack`](https://github.com/Brescou/langgraph-agent-stack).
The upstream project is not modified, and this record does not claim upstream
adoption or independent business-user validation.

v4.36 实现新的产品迭代方案中的 P1 技术预演部分，新增 LangGraph v2 生命周期适配器，
并针对固定 commit 的公开项目做可复现验证。没有修改上游项目，也不把技术预演写成上游
采用或独立业务用户验证。

## API boundary / API 边界

```python
from agent_regression import trace_from_langgraph_events

trace = trace_from_langgraph_events(
    events,
    final_output,
    request,
    run_id="research-123",
    claims_extractor=extract_claims_from_actual_output,
)
```

The adapter records only framework-exposed lifecycle events. It does not infer
hidden tool arguments, decide whether a search result is factually correct, or
replace the application's business Contract.

适配器只记录框架实际暴露的生命周期事件，不推断隐藏的工具参数，不判断搜索结果事实正确性，
也不替代业务方的 Contract。

## Not yet accepted / 尚未验收

- A public-project technical preview is not maintainer adoption.
- Mock output is deterministic integration evidence, not online model quality.
- The required 10–20 business-reviewed cases are not yet available for this
  public project.
- P3 still requires independent users, independent projects and continued CI
  use over real change cycles.

- 公开项目技术预演不等于维护者采用；
- mock 输出是确定性接入证据，不是在线模型质量；
- 还没有该项目业务审核的 10–20 个案例；
- P3 仍需要独立使用者、独立项目和真实改动周期中的持续 CI 使用。
