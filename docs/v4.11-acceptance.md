# v4.11 acceptance / v4.11 验收

v4.11 adds an independently maintained project dataset to the release evidence.
It measures Agent Regression Kit against published τ²-bench retail trajectories
instead of relying only on project-owned fixtures.

v4.11 把第三方维护的公开项目数据加入发布证据。它使用 τ²-bench 已发布的零售 Agent
轨迹衡量框架效果，不再只依赖本项目自建 Fixture。

## Evidence flow / 证据流

```text
pinned upstream JSON + SHA-256
        ↓
tau2 messages → AgentTrace
        ↓
task actions → deterministic ContractPolicy
        ↓
contract decision (reward still hidden)
        ↓
compare with upstream reward → confusion matrix
```

The importer canonicalizes only argument order that the upstream retail tools
treat as order-independent. Failed write attempts may be retried; successful
unexpected writes remain blocking. Required communication is derived from Agent
messages using the upstream substring rule.

导入器只归一化上游零售工具明确视为无序的参数。失败写操作可以重试；成功的未知写
操作仍会阻断。必须传达的信息按照上游子串规则从 Agent 消息中提取。

## Interpretation boundary / 解释边界

This result proves measured behavior on one independently maintained published
dataset. It does not claim upstream adoption or endorsement. The 14 false alarms
are release evidence, not discarded outliers, and motivate explicit final-state
equivalence rules in a later version.

该结果证明框架在一份独立维护的公开数据集上的实测表现，不代表上游采用或背书。
14 个误报属于正式发布证据，不会作为异常值丢弃；它们说明后续需要显式的最终状态
等价规则。
